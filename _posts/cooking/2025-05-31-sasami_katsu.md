[リュウジさんのバターチキンカツ](https://bazurecipe.com/2022/06/02/%E3%83%90%E3%82%BF%E3%83%BC%E3%83%81%E3%82%AD%E3%83%B3%E3%82%AB%E3%83%84/)を参考にしています！

## 材料
ささみ5〜8切れ分（衣は同じ分量で足りる）

- ささみ…5〜8枚
- 味塩コショウ…適量
- 薄力粉…適量
- スライスチーズ…2〜3枚
- パン粉…適量
- 衣（バッター液）
  - 卵…1個
  - 薄力粉…大さじ4
  - 水…大さじ2

## 作り方

### ささみの下ごしらえ
- ささみのスジを取る
  - キッチンペーパーでスジを掴んでフォークで抑えて引き抜く
  - ささみ崩れちゃうけど仕方ないんかな
  - スジは取らなくてもいいとあるが、子どもも食べるので取ってる

![下ごしらえしたささみを並べてラップをかけたところ](/assets/images/20250531/image-1.jpg){: style="max-width:560px; width:100%; height:auto;" }

- まな板の上に並べてサランラップを敷いて角ハイボールの瓶で叩く

![角ハイボールの瓶で叩いて薄く広げたささみ](/assets/images/20250531/image-2.jpg){: style="max-width:560px; width:100%; height:auto;" }

- 味塩コショウを両面に振る
  - 付けすぎると子どもにとっては辛くなるので注意
- スライスチーズを適当に切ってささみにのせる
  - 2つ折りするか、くるくる巻く

![ささみにスライスチーズをのせたところ。右の3枚には紫蘇も入れる](/assets/images/20250531/image-3.jpg){: style="max-width:560px; width:100%; height:auto;" }

- 薄力粉を周りに振りかけて付ける

### 衣作り
バッター液というらしい

- 卵、薄力粉、水を入れて混ぜる

![チーズを包んだささみと、用意したバッター液とパン粉](/assets/images/20250531/image-4.jpg){: style="max-width:560px; width:100%; height:auto;" }

### 仕上げ
- ささみをバッター液に付けてパン粉をつける
  - バッター液で手がベタベタになるので、バッター液とパン粉で使う手を分けると良いぞ
- 油で揚げて完成！

![パン粉を付けたささみと、きつね色に揚がったささみチーズカツ](/assets/images/20250531/image-5.jpg){: style="max-width:560px; width:100%; height:auto;" }

切り分けて盛り付け！

![切り分けたささみチーズカツ。チーズと紫蘇が見える断面](/assets/images/20250531/image-6.jpg){: style="max-width:560px; width:100%; height:auto;" }

## 感想

ささみがやわらかく、チーズがジューシーでとっても美味しー😋
紫蘇を入れても美味しいし、チーズなくても美味しい！
味塩コショウで味は十分付いている。
