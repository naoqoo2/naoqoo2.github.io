誰でも簡単に作れる！育休メシのコーナー！

![大根や卵、ちくわぶ、餅巾着などの具材をたっぷり詰めたおでんの鍋](/assets/images/20241130/image.jpg){: style="max-width:720px; width:100%; height:auto;" }

今回はおでん！
大根、卵、ちくわぶ、餅巾着など、好きな具材を鍋いっぱいに！

## 材料

具材の量は、鍋の大きさと食べたい量に合わせて！

- 大根…適量
- 卵…適量
- うずらの卵…適量
- ちくわぶ…3本
- 餅巾着
  - 油揚げ…適量
  - 切り餅…適量（半分に切って入れる）
  - 乾燥パスタ…適量（口を留める用）
- さつま揚げ・がんもどきなど、お好みのおでん種…適量
- [紀文 おでん汁の素（顆粒）](https://www.kibun.co.jp/products/all_17610a)…1袋（17g）
- 水…1100ml（おでん汁の素1袋に対して）

商品の目安は1袋に水1000ml。うちは少し薄めに、1100mlで作ってます！

## 作り方

### ゆで卵を先に作る

- 先にゆで卵を作っておく
- ゆでたらすぐに冷水につけて、しっかり冷やす
  - すぐ冷やすと殻がむきやすくなる！
- 冷えたら殻をむいておく

### 餅巾着を作る

![餅巾着に使う油揚げ、半分に切った餅、口を留める乾燥パスタ](/assets/images/20241130/image-5.jpg){: style="max-width:560px; width:100%; height:auto;" }

- 油揚げを袋状に開く
- 餅を半分に切って、油揚げの中に入れる
- 口を閉じて、短く折った乾燥パスタで留める

パスタなら、煮てやわらかくなったら一緒に食べられる！

![半分に切った餅を入れ、乾燥パスタで口を留めた餅巾着](/assets/images/20241130/image-6.jpg){: style="max-width:560px; width:100%; height:auto;" }

### 大根を切る

- 大根の皮をむいて厚めの輪切りにする
- 上下両面に、浅く十字の切り込みを入れる

大根は下ゆでしなくてOK！そのまま鍋へ。

### ちくわぶを切る

![まな板に並べた切る前のちくわぶ3本](/assets/images/20241130/image-2.jpg){: style="max-width:560px; width:100%; height:auto;" }

- 食べやすい大きさに斜め切りにする

![食べやすい大きさに斜め切りにしたちくわぶ](/assets/images/20241130/image-3.jpg){: style="max-width:560px; width:100%; height:auto;" }

### 鍋に具材を入れて煮る


- 大根や餅巾着を入れた鍋に、卵、うずらの卵、切ったちくわぶやさつま揚げなどを入れる

![輪切りの大根と、半分に切った餅を入れてパスタで留めた餅巾着](/assets/images/20241130/image-1.jpg){: style="max-width:560px; width:100%; height:auto;" }

どんどん入れたら鍋がいっぱいになったw

![卵、うずらの卵、ちくわぶやさつま揚げなどを加えたおでんの鍋](/assets/images/20241130/image-4.jpg){: style="max-width:560px; width:100%; height:auto;" }

- おでん汁の素1袋を水1100mlに溶かして、鍋に入れる
- 火にかける
- 煮立ったら弱火にして、30分くらいを目安に煮込む
  - ぐつぐつ煮立てすぎず、コトコト煮る！
  - 大根の厚さなどで時間は変わるので、竹串を刺して、まだかたければ追加で煮る
- 大根に竹串がすっと通り、味が染み込んだら完成！

## メモ

- 具材を入れすぎると煮汁を入れる余裕がなくなるので、鍋いっぱいに詰めすぎないように！
- 具材はお好みで。大きな卵とうずらの卵、両方入れるのも楽しい！

## 感想

好きな具材をたっぷり入れられるのが、おうちおでんのいいところ！
寒い日に食べるおでん、温まるー🍢
